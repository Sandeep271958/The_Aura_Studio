Browser Security & Permissions

Unlock Ambilight Screen Sync & SoundSync Audio Reactive

Insecure Origin Restricted by Google Chrome

Google Chrome requires a "Secure Context" before granting Screen Capture (Ambilight) and Microphone (SoundSync) permissions. Because aura-hub.local is served over local HTTP, Chrome restricts these sensitive media APIs.

OPTION 1 • RECOMMENDED FOR CHROME / EDGE

Enable Chrome's Secure Origin Flag

Takes 30 seconds • Zero downloads • Permanently marks aura-hub.local as Safe & Secure

  1. Open this internal Chrome flags page in a new tab:
    chrome://flags/#unsafely-treat-insecure-origin-as-secure
  2. Set the flag to Enabled.
  3. Paste this hub origin into the text box:
    http://aura-hub.local
  4. Click the blue Relaunch button at the bottom of Chrome.
✓ Removes "Not Secure" warning in Chrome ✓ Unlocks full Ambilight & SoundSync
OPTION 2 • COMPANION RUNNER

Run via Localhost Companion Mode

W3C standards define localhost as an automatic Secure Context with 0 warnings

  1. Run the included zero-dependency companion script in terminal:
    python3 scripts/run_local.py
  2. Or double-click start_dashboard.command on macOS.
  3. Chrome immediately opens http://localhost:8080 with 100% native Secure Context.
✓ Native browser security (no flags needed) ✓ Connects live to ws://aura-hub.local/ws
